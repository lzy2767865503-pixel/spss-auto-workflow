# Survey Data Workbench by LAI ZEYU Privacy Policy

**Effective date:** 27 August 2026

Permanent public policy URL:
https://github.com/lzy2767865503-pixel/spss-auto-workflow/blob/main/store/PRIVACY_POLICY.md

Developer / 开发者: **LAI ZEYU（来泽宇）**.

Survey Data Workbench by LAI ZEYU is a local survey-analysis application. The application does
not require an account and does not include advertising, analytics telemetry, or
an application-operated cloud upload service.

## Data processed

When a user selects a dataset, Survey Data Workbench by LAI ZEYU processes that file on the
user's device to inspect variables, generate Python-based statistical previews,
create interoperability syntax, and prepare downloadable results. Dataset
content, job configuration, generated files, and local service logs may be
stored in the application's private local data directory.

## Storage and retention

Local jobs are retained for 30 days by default. The user can change the
retention period from 1 to 3,650 days and can delete all application-managed
datasets, job configurations, previews, and outputs at any time from
**Settings > Delete all task data**. This control does not reset the retention
preference, delete rotating local service logs, or clear Microsoft Edge WebView2
support data. Service logs rotate at approximately 2 MB with up to three backup
files. WebView2 support data and preferences remain until Windows application
reset, uninstall, or manual operating-system cleanup. Uninstall
behaviour should be verified on the final Store package; users should use the
in-app task-data deletion control before uninstalling when assured removal of
datasets and generated results is required.

## Data sharing and network use

Survey Data Workbench by LAI ZEYU does not transmit uploaded research data to a service
operated by the developer. The desktop interface communicates with a local
service bound to `127.0.0.1` using a random port and a per-launch token.

Microsoft Edge WebView2, Windows, IBM SPSS Statistics, or other user-installed
software may operate under their own terms and privacy policies. IBM SPSS
Statistics interoperability is optional and runs only against software the user
has installed and licensed separately.

## User responsibilities

Users are responsible for having a lawful basis to process respondent or
personal data, applying appropriate consent and de-identification measures, and
checking generated files before sharing them.

## Contact and changes

For product support, bug reports, and privacy questions that do not contain
sensitive data, open a repository issue:
https://github.com/lzy2767865503-pixel/spss-auto-workflow/issues

Report security vulnerabilities privately through GitHub Security Advisories:
https://github.com/lzy2767865503-pixel/spss-auto-workflow/security/advisories/new

Do not include datasets, respondent records, credentials, licence information,
or other personal or confidential information in a public issue. Material
policy changes will be dated and published at the permanent public policy URL
above by LAI ZEYU（来泽宇）.
