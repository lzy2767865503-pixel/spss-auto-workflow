### Short description

files locally—with optional interoperability for a separately installed and
licensed IBM SPSS Statistics environment.

### Full description

Requires a separately installed and licensed IBM SPSS Statistics for optional
formal SPSS execution. Survey Data Workbench by LAI ZEYU guides students and researchers through survey-data setup.
Import Excel, CSV, text, SAV, ZSAV, or POR files; review detected constructs;
choose descriptive, reliability, correlation, factor, and regression workflows;
then download reproducible previews and syntax.

Python preview results are explicitly labelled as previews. SAV, SPV, and PDF
files are shown as format-complete IBM SPSS outputs only when the user's local
IBM SPSS Statistics execution returns a valid completion marker and SAV/SPV/PDF
all pass full parsers. Statistical-semantic release validation is a separate
two-authorised-environment gate and is not inferred from file headers.
IBM SPSS Statistics is optional, proprietary, and not included.

Data stays in the application's local data directory. Users can change the
retention period or delete all uploaded datasets, job configurations, previews,
and generated outputs from Settings. This task-data control does not reset
preferences or remove rotating technical logs and WebView2 support data.

## Feature bullets

- Configurable local retention and one-click task-data deletion
- Chinese-language workflow with clear execution provenance
