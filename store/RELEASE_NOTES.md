# Release Notes — 1.1.0 Windows Store Candidate

Developer / 开发者: **LAI ZEYU（来泽宇）**

Requires a separately installed and licensed IBM SPSS Statistics for optional
formal SPSS execution. IBM software and licences are not bundled.

## Candidate scope

- Adds a self-contained .NET 8 WPF and WebView2 x64 desktop shell.
- Packages the Waitress/Flask analysis service as a local PyInstaller sidecar.
- Uses a random loopback port, a per-launch token, local-origin validation, and
  defensive response headers.
- Separates Python previews, fully parsed IBM SPSS file-format integrity, and
  the still-external two-authorised-environment semantic result gate; removes
  partial or unreadable formal files after failure.
- Adds configurable local retention, in-app task-data deletion, bilingual Store
  copy, privacy and certification drafts, exact per-candidate third-party
  notices, and hash-bound Windows quality gates. Hosted gates upload no artifact;
  only a protected organisation runner-group builder may move the exact
  current-`main` unsigned candidate to a principal-specific private ACL share.
  Protected interactive Windows 10/11 jobs each freeze one temporary-signed MSIX
  and reuse it byte-for-byte for two strict WACK and installed lifecycle passes.
  They verify the protected-approved appcert hash/version, fresh report hash,
  external exact product title, one loopback listener, safe process identity,
  forced-exit cleanup, relaunch, exact uninstall, and `LocalState` removal. No
  production binary includes a CI evidence/DOM automation path. Only fixed-schema
  canonical JSON plus SHA-256 may upload after success, never raw evidence or the
  unsigned candidate.
- Separates public GitHub delivery from the Store identity. The public path
  builds an EXE installer, signs every nested PE, the uninstaller, and installer
  in a no-checkout clean signing domain through a pinned out-of-repository
  SSL.com eSigner CKA/Windows SignTool harness. A real recursive inventory must
  prove one exact `LAI ZEYU`/`来泽宇` thumbprint, RFC 3161 timestamp, and TSA EKU
  for every PE without launching repository-derived binaries. After complete
  signing-credential cleanup, a separate no-signing verifier account performs
  two identical-byte lifecycle passes and freezes a new publisher handoff. Two
  reviewer-approved private licensed-SPSS assertions bind semantic comparisons
  to the tag, integration source, and exact built private layout. Their shared
  HMAC is integrity-only and does not prove independent environment facts or
  claim that the later signed EXE/Partner Center MSIX was tested. The no-checkout
  exact-ID publisher never adopts an ambiguous create and rolls back only its
  verified numeric Release ID.
